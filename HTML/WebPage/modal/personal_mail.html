주제

  • Naver Worksmoblie API를 이용한 MailSend 시스템

주요기능

  • 기존의 사용자 관리 시스템, CRM 시스템, 웹 애플리케이션과 연동하여 메일을 발송
  • 외부 시스템이나 애플리케이션에서 메일 발송 요청을 할 수 있어 매우 유연한 운영이 가능

인원

  • 1명

나의 기여

  • 프론트엔드 디자인 및 UI 구현
  • 백엔드 API 설계 및 구현

개발기간

  • 2025년 3월 4일 - 2025년 3월 7일

문제점

  • Token 갱신 문제
  • JSON 데이터 처리 문제

사용기술

  • HTML, CSS, JavaScript, PHP
  • MySQL 데이터베이스

해결방법

  • Token 갱신 문제

    • Access token이 1시간 또는 24시간마다 만료됨.

    API 호출 시 HTTP 404 오류가 발생하면, Access Token이 만료된 것으로 간주하고 Refresh Token을 사용해 Access Token을 갱신

    갱신된 Access Token, Refresh Token을 데이터베이스에 업데이트


  • JSON 데이터 처리 문제

    • API 호출을 했을 때 응답으로 JSON을 받을 것이라고 예상하고 코드를 작성

    그러나 API에서 HTTP 202 상태 코드를 반환

    HTTP 202 응답을 성공 응답으로 처리하도록 수정
