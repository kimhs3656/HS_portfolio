주제

  • 사용자의 전력 요금과 사용량을 실시간으로 조회할 수 있는 웹 사이트.

주요기능

  • 전력 요금 계산기
  • 실시간 전력 사용량 조회
  • 사용자별 요금 히스토리 보기

사용기술 및 언어

  • HTML, CSS, JavaScript
  • Node.js, Express.js
  • MySQL 데이터베이스

작업 기여도

  • 프론트엔드 디자인 및 UI 구현
  • 백엔드 API 설계 및 구현
  • 배포 및 유지보수

문제점

  • 실시간 데이터 업데이트 문제
  • 사용자 인증 및 보안 문제
  • 대규모 트래픽 처리 성능 문제
